=== WoozOffline Custom Asset & Texture Pack Folder ===

You can place your own extracted Flash/PNG/SVG/Audio assets in this directory:

1. Clothing Sprites:
   - Place image files in `/public/custom_assets/clothing/`
   - Supported formats: .png, .svg, .webp

2. Furniture Textures:
   - Place image files in `/public/custom_assets/furniture/`
   - Supported formats: .png, .svg, .webp

3. Sound Effects & Music:
   - Place audio files in `/public/custom_assets/audio/`
   - Supported formats: .mp3, .wav, .ogg

4. Room Definitions:
   - Place room JSON files in `/public/custom_assets/rooms/`

The game engine will automatically detect and load these assets!
